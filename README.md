# kd.inc — Official Website

Official website for **kd.inc** — an ingeniously disruptive, 100% black-owned & managed South African investment company driving financial and digital inclusion across property, healthcare, telecom, and finance.

## Development

Requires Node.js (v18+) and npm.

```sh
npm i
npm run dev
```

## Production Build

```sh
npm run build
```

## Built With

- TanStack Start & TanStack Router
- React 19
- TypeScript
- Tailwind CSS & GSAP
- Vercel Deployment Support
